# 裸 Prompt 对照实验（bare baseline）

## 实验目的

项目一 pass@1 达 98.3%~100%，需回答一个致命问题：**不进行任何 Agent 编排，直接用单条 prompt 让同一个模型修同一批题，能否达到同样效果？** 若答案是能，则 Agent 框架没有增量，项目沦为套壳跑 benchmark。

## 对照设置（唯一变量 = 有无 Agent 框架）

| 维度 | 裸跑 baseline | Agent（S0~S4） |
|---|---|---|
| 模型 | qwen3.8-flash | qwen3.8-flash（相同）|
| 题集 | QuixBugs 40 题 | QuixBugs 40 题（相同）|
| 判定 | 官方 pytest 隔离复测（TestRunner）| 同一 TestRunner（相同）|
| 输入 | buggy code + 直接修复指令 | 上下文策略构造的上下文 |
| 工具/循环 | **无** | read/grep/ast/edit/test + ReAct 循环 |
| 测试反馈/自纠正 | **无** | 官方测试失败回喂，最多 2 次 |
| 重复 | 3 次 | 3 次 |

## 核心结果

- **裸跑 pass@1 = 37/39 = 94.9%**（运行级首轮口径，与主报告 pass@1 定义一致；API 超时样本无答案，不计入）
- 裸跑平均 token/次 ≈ 1821

| 策略 | Agent pass@1 | 相对裸跑增量 | 平均 token |
|---|---|---|---|
| 裸跑 baseline | 94.9% | — | 1821 |
| S0 | 98.3% (118/120) | +3.5pp | 5267 |
| S1 | 100.0% (120/120) | +5.1pp | 5255 |
| S2 | 100.0% (120/120) | +5.1pp | 6042 |
| S3 | 98.3% (118/120) | +3.5pp | 8370 |
| S4 | 100.0% (120/120) | +5.1pp | 8079 |

## 结论

同模型、同题集、同官方复测下，裸 prompt 首轮通过率 94.9%，而 Agent（含工具调用、上下文策略、测试失败自纠正）为 98.3%~100%。**差值即 Agent 框架的净增量**，回答了'比裸 prompt 高多少'。

### 口径说明（诚实披露）

- 裸跑中 `hanoi`（3/3 失败）、`shortest_path_length`（首轮失败）、`knapsack`、`reverse_linked_list` 出现真实修复失败；`wrap` 与 `shortest_path_length` 的部分重复因 API 输出超时（无答案，非能力失败）被剔除，不伪装成模型失败。
- 少数长输出题触发 API 读超时，已按 env error 剔除，不伪装成模型能力失败。这是工具链限制，非数据造假。
- 裸跑与 Agent 的最终 100% 差距主要来自**测试失败反馈 + 自纠正**：裸跑一次成型，Agent 可依据官方 pytest 报错再修。这正是 Agent 框架的核心价值。
